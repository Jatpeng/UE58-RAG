# 03 索引与检索

本篇介绍 Lexical、向量、Hybrid 和 Rerank 四种检索层。

## 1. Lexical 检索

Lexical 使用 SQLite FTS5，擅长查找精确符号、类名、函数名、宏名、路径和源码关键词。

全量重建：

```powershell
Set-Location "E:\UE5.8 RAG"
python scripts/build_lexical_index.py `
  --rebuild `
  --batch-size 2048 `
  --progress-every 100000
```

检查索引数量：

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/index/lexical.sqlite3'); print('chunks=',c.execute('select count(*) from chunks').fetchone()[0]); print('fts=',c.execute('select count(*) from chunks_fts').fetchone()[0]); c.close()"
```

查询符号：

```powershell
python scripts/query.py `
  "UCharacterMovementComponent::MaxWalkSpeed" `
  --mode symbol `
  --index data/index/lexical.sqlite3 `
  --limit 5
```

查询自然语言关键词：

```powershell
python scripts/query.py `
  "network prediction character movement" `
  --mode lexical `
  --index data/index/lexical.sqlite3 `
  --limit 5
```

## 2. Embedding 向量

Embedding 将每个 chunk 转换为固定长度的向量。文档和查询必须使用同一个模型、同一个维度和同一种归一化方式。

生成向量：

```powershell
python scripts/embed.py `
  --input data/chunks/engine/chunks.jsonl `
  --output data/embeddings/engine/embeddings.npy `
  --batch-size 16 `
  --max-length 2048 `
  --progress-every 10000
```

输出包括 `.npy` 向量矩阵、ID 映射文件和 manifest 文件。

## 3. Qdrant 索引

Embedding 完成后导入 Qdrant：

```powershell
python scripts/build_index.py `
  --input data/chunks/engine/chunks.jsonl `
  --vectors data/embeddings/engine/embeddings.npy `
  --ids data/embeddings/engine/embeddings.npy.ids.jsonl
```

如果模型或向量维度改变，应使用新集合或明确使用 `--recreate` 重建。

## 4. Hybrid 检索

Hybrid 同时执行 dense 和 sparse 检索，再通过 RRF（Reciprocal Rank Fusion）合并排名：

```powershell
python scripts/query.py `
  "UE5.8 角色移动网络预测" `
  --mode hybrid `
  --index data/index/lexical.sqlite3
```

Hybrid 要求 Qdrant 向量集合和 Embedding Provider 都已经可用。

## 5. Rerank

Reranker 对 Hybrid 返回的候选结果再次排序：

```powershell
python scripts/query.py `
  "UE5.8 角色移动网络预测" `
  --mode rerank `
  --index data/index/lexical.sqlite3
```

Rerank 通常只处理前几十条候选，不应把整个语料库直接交给重排模型。

## 6. 检索参数调优

推荐调优顺序：

1. 先保证符号精确命中。
2. 再调整 Lexical Top-K。
3. 再调整 Dense Top-K 和 RRF 常数。
4. 最后调整 Rerank 候选数量和最终 Top-K。

必须使用固定问题集比较 Hit@K、Recall、MRR 和 nDCG，不能只凭主观感受判断质量。
