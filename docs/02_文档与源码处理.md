# 02 文档与源码处理

本篇说明如何把 UE 官方文档和 Unreal Engine C++ 源码转换为统一的 RAG 数据。

## 1. 下载官方文档

```powershell
Set-Location "E:\UE5.8 RAG"
python scripts/ingest_docs.py --topic cpp --dry-run
```

小规模抓取：

```powershell
python scripts/ingest_docs.py --topic cpp --max-pages 10 --max-depth 1
```

确认结果正常后，再逐步增加页面数。抓取器会保存 manifest、校验和以及缓存，适合中断后继续运行。

## 2. 解析 HTML 文档

```powershell
python scripts/parse_docs.py
```

输出：

```text
data/parsed/docs/documents.jsonl
data/parsed/docs/issues.jsonl
```

解析器会清理导航、页脚、侧边栏、Cookie UI 和复制按钮，同时保留标题、标题层级、段落、表格、列表、链接、提示和代码块。

## 3. 文档语义切块

```powershell
python scripts/chunk_docs.py
```

输出：

```text
data/chunks/docs/chunks.jsonl
```

切块原则：

- 优先按 H1/H2/H3 层级切分。
- 小节未超限时保持完整。
- 大段内容按目标长度切分并保留重叠。
- 每个 chunk 重复完整标题路径和来源信息。
- 代码块保持不可拆分。

## 4. 扫描 Unreal Engine 源码

在 `config/ue58.yaml` 设置 `engine.root`，指向包含 `Engine/` 的目录：

```powershell
python scripts/ingest_engine.py --dry-run
python scripts/ingest_engine.py
```

扫描结果：

```text
data/parsed/engine/files.jsonl
data/parsed/engine/issues.jsonl
```

扫描器记录相对路径、模块、插件、文件类型、文件大小、UE 版本和 SHA-256。

## 5. 解析 C++ 符号

完整解析：

```powershell
python scripts/parse_engine.py
```

小范围验证：

```powershell
python scripts/parse_engine.py `
  --path-contains CharacterMovementComponent `
  --limit-files 20 `
  --output work/t07_character_movement.jsonl
```

解析器按类、结构体、枚举、函数、方法、构造函数和字段生成文档，并保留以下 UE 宏：

```text
UCLASS USTRUCT UENUM UINTERFACE UFUNCTION UPROPERTY UDELEGATE
```

## 6. C++ 语义切块

```powershell
python scripts/chunk_engine.py
```

小范围切块：

```powershell
python scripts/chunk_engine.py `
  --input work/t07_character_movement.jsonl `
  --output work/t08_character_movement.jsonl
```

函数通常保持完整；过大的函数或类型会按源代码行拆分，并在每个部分重复模块、类、符号和文件上下文。

## 7. 质量检查

```powershell
python -c "from pathlib import Path; p=Path('data/chunks/engine/chunks.jsonl'); print('chunks=',sum(1 for line in p.open(encoding='utf-8') if line.strip()))"
```

重点检查：

- `id` 是否唯一。
- `engine_version` 是否为 `5.8`。
- `content` 是否为空。
- `file_path`、`module`、`symbol` 是否正确。
- `issues.jsonl` 是否有大量异常。
