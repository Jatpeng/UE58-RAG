## 4. 常见错误

### 找不到 mcp_server.py

终端当前目录错误。先执行：

```powershell
Set-Location "E:\UE5.8 RAG"
python scripts/mcp_server.py
```

文件名是 `mcp_server.py`，不要写成 `mcp\_server.py`。

### 路径变成 C:\Windows\System32

说明终端当前目录是 System32，而不是项目目录。使用项目绝对路径或先 `Set-Location`。

### MCP 报 Invalid JSON: EOF

stdio 服务正在等待 MCP 客户端发送 JSON-RPC。不要在服务终端手动敲空行，应从 Cursor 或 Claude 配置并启动。

### 浏览器访问 /mcp 返回 406

`/mcp` 是 MCP 协议端点，不是 HTML 页面。浏览器 GET 没有提供 MCP 所需的请求格式，返回 406 属于预期现象。

### CUDA 为 False

检查 `nvidia-smi` 是否能找到显卡，并确认 PyTorch 版本包含 CUDA 标记，例如 `+cu130`，而不是 `+cpu`。

### Embedding 内存不足

降低 batch 和 token 上限：

```powershell
python scripts/embed.py `
  --input data/chunks/engine/chunks.jsonl `
  --output data/embeddings/engine/embeddings.npy `
  --batch-size 4 `
  --max-length 1024
```

### SQLite 拒绝替换

通常是 MCP 或其他查询进程仍打开旧索引。先停止服务，再进行索引替换。
